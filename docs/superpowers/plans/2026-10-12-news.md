# Vārtā v2 — Sub-project 4: News + Sentiment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ingest news from Alpaca (Benzinga), Finnhub, RSS, GDELT and SEC EDGAR plus Polymarket crowd odds; dedupe and tag them to the user's holdings and geopolitical topics; score each (item, ticker) pair with TypeSafe Jev; serve a scored news feed, daily sentiment, crowd odds and holdings through the API; switch the web News and Investments pages to live data.

**Architecture:** Pure text utilities (normalize, hash, tag) live in `core/news.py`. Each source is a small fail-soft function in `api/news_sources.py` that returns normalized `RawItem`s over `httpx` (transport injectable for tests). Scoring sits behind a `Scorer` protocol: `TypeSafeScorer` calls `POST https://api.typesafe.ai/v1/systemone`; `HeuristicScorer` is a deterministic keyword fallback used offline, in tests and in the demo when no key is set (`scored_by` records which). `api/news_pipeline.py::refresh_news` orchestrates fetch → dedupe → tag → store → score → retention. Policy thresholds (noise / materiality) are applied at read time, so they change without re-scoring. Scheduling arrives with the worker in sub-project 6; here a CLI runs a refresh.

**Tech Stack:** Python 3.12, httpx, stdlib `xml.etree` (RSS), Polars, SQLite, FastAPI; Next.js server components + node:test.

**Spec:** `docs/superpowers/specs/2026-10-11-varta-v2-design.md` (§5 news + public sentiment, §4 `get_news` / `get_sentiment` shapes, §6 News + Investments pages, §8 item 4)

## Global Constraints

- Sources and limits (verified 2026-10-12 unless marked):
  - Alpaca news `GET https://data.alpaca.markets/v1beta1/news` with headers `APCA-API-KEY-ID` / `APCA-API-SECRET-KEY`; params `symbols` (comma list), `limit`, `sort=desc`; items `headline, summary, url, source, created_at, symbols` (from working v1 code).
  - Finnhub `GET https://finnhub.io/api/v1/company-news?symbol=&from=&to=&token=`; items `headline, summary, url, source, datetime` (unix seconds) (v1 code). Max 8 symbols per run (free tier).
  - RSS: MarketWatch `https://feeds.content.dowjones.io/public/rss/mw_topstories` and `…/mw_marketpulse` (HTTP 200 verified); parse `<item><title><link><pubDate><description>` with stdlib `xml.etree.ElementTree`.
  - GDELT DOC 2.0 `GET https://api.gdeltproject.org/api/v2/doc/doc?query=&mode=artlist&format=json&maxrecords=<=250&timespan=1d&sort=datedesc`. **Rate limit: one request per 5 seconds** (server message). Article fields assumed `url, title, seendate (YYYYMMDDTHHMMSSZ), domain` — unverified (probe was rate-limited); parse defensively, skip items missing url/title.
  - SEC EDGAR: ticker map `https://www.sec.gov/files/company_tickers.json` (`{"0": {"cik_str", "ticker", "title"}}`), submissions `https://data.sec.gov/submissions/CIK##########.json` (`filings.recent.form/filingDate/accessionNumber/primaryDocument` arrays, v1 code). Requests need a descriptive `User-Agent` with contact info from env `SEC_USER_AGENT`; **skip EDGAR when unset**. Only form `8-K`.
  - Polymarket Gamma `GET https://gamma-api.polymarket.com/markets?active=true&limit=500&offset=` (300 req/10 s); fields `question, outcomePrices (JSON string), liquidity, endDate, slug`. Keyword include/exclude lists from v1 (`legacy/src/data/fetchers.py:245-256`).
  - TypeSafe `POST https://api.typesafe.ai/v1/systemone`, header `Authorization: Bearer <TYPESAFE_API_KEY>`, body `{state, model: "jev-latest", questions}`; answers keyed by question id: noul → `{"noul": p}`, choice → `{"choice", "probabilities", "confidence"}`, score → `{"score", "probabilities", "confidence", "legend"}`. 429/529 → retry with exponential backoff (max 3 attempts).
- Every source is fail-soft: network/HTTP/parse errors log the source name + error type only and return `[]`. One source failing never stops a refresh.
- Keys never logged or returned. Env: `ALPACA_API_KEY`, `ALPACA_SECRET_KEY`, `FINNHUB_API_KEY`, `TYPESAFE_API_KEY`, `SEC_USER_AGENT` (all optional; missing → that source/scorer is skipped/falls back).
- Dedupe: `url_hash = sha1(normalized url)`; `title_hash = sha1(normalized title)` (lowercase, strip punctuation, collapse spaces). An item is a duplicate if either hash exists.
- Tagging is deterministic: source-provided symbols first; else whole-word ticker or company-alias match against tracked securities; topics from the v1 geopolitical keyword list. Items with no ticker get pseudo-ticker `"MARKET"` (broad-market sentiment).
- Score questions exactly as in spec §5 (sentiment 5-level Score, material Noul, stress 4-level Score, event Choice, noise Noul). Sentiment value = `(score − 2) / 2` ∈ [−1, 1]. Stress label = level of `round(score)`.
- Read-time policy: an item is shown in the default feed when `noise <= 0.7` and `material >= 0.3` (`NOISE_MAX`, `MATERIAL_MIN`). Daily sentiment = confidence-weighted mean of sentiment per (ticker, day, channel); channel is `"news"` (Reddit is `"crowd"` later).
- Scoring budget: at most `MAX_SCORES_PER_RUN = 200` pairs per refresh, newest first. Retention: delete `news_items` older than 90 days (scores cascade).
- Python: Polars only, docstrings, named constants, no import-time I/O, tests never hit the network. `uv run pytest -q && uv run ruff check .` green.
- Web: tested modules use relative `.ts` imports; `cd web && pnpm typecheck && pnpm test && pnpm build` green. After API changes: `uv run python -m scripts.dump_openapi && (cd web && pnpm gen:api)`.
- Commits: Conventional Commits, **no `Co-Authored-By` line**.

## Review Focus

1. **A source is down, slow or returns junk** (HTTP 500, timeout, HTML instead of JSON, GDELT's plain-text rate-limit message): that source yields nothing, the others still land, refresh returns per-source counts. Tests in Tasks 3–4 and 6.
2. **The same story from several sources** (identical headline, URL with tracking params, different capitalization/punctuation): stored once. Test in Task 2 and 6.
3. **TypeSafe unavailable** (no key, 401, 429 storm, 529): items still stored; scoring falls back to the heuristic scorer or leaves pairs unscored for the next run — never crashes the refresh; `scored_by` shows which. Tests in Tasks 5–6.
4. **Ticker false positives** ("AMD" inside "AMDocs", "SPY" in "spyware", single-letter tickers): whole-word, case-sensitive ticker matching only; company aliases case-insensitive whole words. Test in Task 2.
5. **Empty news DB / API down**: `/api/news`, `/api/sentiment`, `/api/crowd_odds`, `/api/holdings` return 200 empty; web News and Investments show empty / unreachable states, not mock data. Tests in Tasks 7–10.

```python
"""News text utilities: normalization, dedupe hashes and deterministic tagging."""

import hashlib
import re
import string
from dataclasses import dataclass
from urllib.parse import parse_qsl, urlencode, urlsplit, urlunsplit

TRACKING_PREFIXES = ("utm_", "fbclid", "gclid")
_PUNCT = re.compile(f"[{re.escape(string.punctuation)}—–‘’“”]")
_SPACES = re.compile(r"\s+")
GEO_TOPICS: dict[str, tuple[str, ...]] = {
    "geopolitics": ("sanction", "invasion", "missile", "ceasefire", "tariff", "embargo", "nato",
                    "taiwan", "iran", "ukraine", "russia", "strait of hormuz", "red sea"),
    "energy": ("opec", "brent", "crude", "oil supply", "natural gas"),
    "semiconductors": ("chip", "semiconductor", "export control", "foundry"),
    "macro": ("federal reserve", "rate cut", "rate hike", "inflation", "recession", "treasury yield"),
}


@dataclass(frozen=True)
class RawItem:
    """A news item normalized from any source."""

    source: str
    url: str
    title: str
    text: str
    published_at: str
    symbols: tuple[str, ...] = ()


def normalize_title(title: str) -> str:
    """Lowercase, drop punctuation, collapse whitespace."""
    return _SPACES.sub(" ", _PUNCT.sub(" ", title.lower())).strip()


def normalize_url(url: str) -> str:
    """Canonical URL: lowercase scheme/host, no tracking params, no fragment, no trailing slash."""
    parts = urlsplit(url.strip())
    query = urlencode([(k, v) for k, v in parse_qsl(parts.query, keep_blank_values=True)
                       if not k.lower().startswith(TRACKING_PREFIXES)])
    path = parts.path.rstrip("/")
    return urlunsplit((parts.scheme.lower(), parts.netloc.lower(), path, query, ""))


def url_hash(url: str) -> str:
    """Dedupe key for a URL."""
    return hashlib.sha1(normalize_url(url).encode()).hexdigest()


def title_hash(title: str) -> str:
    """Dedupe key for a headline."""
    return hashlib.sha1(normalize_title(title).encode()).hexdigest()


def tag_tickers(item: RawItem, securities: dict[str, tuple[str, ...]]) -> list[str]:
    """Tracked tickers this item is about: source symbols first, else text matching."""
    given = [s for s in item.symbols if s in securities]
    if given:
        return sorted(set(given))
    text = f"{item.title} {item.text}"
    lower = text.lower()
    found = set()
    for ticker, aliases in securities.items():
        if re.search(rf"(?<![A-Za-z0-9]){re.escape(ticker)}(?![A-Za-z0-9])", text):
            found.add(ticker)
        elif any(re.search(rf"\b{re.escape(a.lower())}\b", lower) for a in aliases):
            found.add(ticker)
    return sorted(found)


def tag_topics(text: str) -> list[str]:
    """Geopolitical/macro topics mentioned in the text."""
    lower = text.lower()
    return sorted(t for t, kws in GEO_TOPICS.items() if any(k in lower for k in kws))
```
