# Vārtā v2 — Sub-project 2: Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the v0-generated UI into `web/` with dependency hygiene, fix the four known UI defects, and wire the first real data path (sidebar regime badge ← `/api/regime`) through a typed client generated from FastAPI's OpenAPI schema.

**Architecture:** `web/` is a Next.js App Router app (from v0 chat `sGWEk7apDEm`) that still renders mock data from `lib/mock-data.ts`. Pure display logic moves into small dependency-free modules in `web/lib/` (`recurring.ts`, `avatar.ts`, `sparkline.ts`, `regime-badge.ts`), unit-tested with Node's built-in test runner (no Vitest/Jest). In dev, Next rewrites `/api/*` to FastAPI, so the browser talks to one origin. FastAPI's schema is committed as `web/openapi.json`; `openapi-typescript` turns it into `web/lib/api-types.ts`; a pytest snapshot test fails when the API changes without regenerating.

**Tech Stack:** Next.js 16, React 19, TypeScript 5.7, Tailwind 4, shadcn (base-nova), Recharts 3, pnpm 11, Node 22 (`node --test` with type stripping), openapi-typescript 7; FastAPI + Pydantic on the API side.

**Spec:** `docs/superpowers/specs/2026-10-11-varta-v2-design.md` (§6 UI incl. "Known UI fixes", §3 `recurring_streams.kind`, §7 testing, §8 item 2)

## Global Constraints

- Node 22 and pnpm 11 (local: node v22.23.0, pnpm 11.8.0). `packageManager` field = `pnpm@11.8.0`.
- No new runtime dependencies except `openapi-typescript` (dev). No Vitest, Jest, Playwright, or analytics SDKs.

- Python side: the Foundation rules (CLAUDE.md) still apply: Polars only, docstrings, `uv run pytest && uv run ruff check .` green.

## Review Focus

1. **Merchant names with leading spaces, lowercase, or non-ASCII (e.g. "  dropbox", "Ōura")**: avatar shows a sensible uppercase initial and a stable color, never an empty circle. Test in Task 3.
2. **Sparkline with one point, all-equal values, or an empty array**: renders a flat line or nothing, never `NaN` in the SVG path (which blanks the whole cell). Test in Task 4.
3. **API down or `/api/regime` returns 503**: sidebar badge shows "REGIME UNAVAILABLE" in a neutral tone; the page never crashes or shows a stale "NORMAL". Test in Task 6.
4. **Annual and weekly subscriptions in the monthly total**: annual divided by 12, weekly times 52/12; bills never counted in the subscriptions total. Test in Task 2.
5. **API changes without regenerating the client**: the OpenAPI snapshot test fails in CI. Test in Task 5.

```ts
import type { Bill, RecurringKind } from "./types.ts"

export const WEEKS_PER_MONTH = 52 / 12
const MONTHS_PER_YEAR = 12

type Frequency = Bill["frequency"]
type RecurringLike = { kind: RecurringKind; amount: number; frequency: Frequency; inactive?: boolean }

/** Convert a charge to its average monthly cost. */
export function monthlyCost(amount: number, frequency: Frequency): number {
  if (frequency === "Annual") return amount / MONTHS_PER_YEAR
  if (frequency === "Weekly") return amount * WEEKS_PER_MONTH
  return amount
}

/** Split recurring charges into subscriptions and bills with monthly totals (inactive excluded). */
export function splitRecurring<T extends RecurringLike>(items: T[]) {
  const total = (xs: T[]) =>
    xs.filter((x) => !x.inactive).reduce((sum, x) => sum + monthlyCost(x.amount, x.frequency), 0)
  const subscriptions = items.filter((x) => x.kind === "subscription")
  const bills = items.filter((x) => x.kind === "bill")
  return { subscriptions, bills, subscriptionsMonthly: total(subscriptions), billsMonthly: total(bills) }
}
```

```ts
/** Muted, mutually distinct fills that keep white text readable on #0a0a0a. */
export const AVATAR_COLORS = [
  "#3b5b8c", "#7a4b8c", "#3f7a5a", "#9a5b3a",
  "#8c3b4f", "#2f7a80", "#7a6a2f", "#5a5a6e",
] as const

const FALLBACK_INITIAL = "?"

/** First visible letter of a merchant name, uppercased. */
export function avatarInitial(merchant: string): string {
  const first = [...merchant.trim()][0]
  return first ? first.toLocaleUpperCase() : FALLBACK_INITIAL
}

/** Stable palette color for a merchant (FNV-1a hash of the normalized name). */
export function avatarColor(merchant: string): string {
  let hash = 0x811c9dc5
  for (const ch of merchant.trim().toLowerCase()) {
    hash ^= ch.codePointAt(0) ?? 0
    hash = Math.imul(hash, 0x01000193) >>> 0
  }
  return AVATAR_COLORS[hash % AVATAR_COLORS.length]
}
```

```ts
const DEFAULT_PAD = 2
const round = (n: number) => Math.round(n * 100) / 100

/** SVG path for a sparkline; y is inverted so higher values sit higher. */
export function sparklinePath(values: number[], width: number, height: number, pad = DEFAULT_PAD): string {
  const pts = values.filter((v) => Number.isFinite(v))
  if (pts.length === 0) return ""
  const series = pts.length === 1 ? [pts[0], pts[0]] : pts
  const min = Math.min(...series)
  const max = Math.max(...series)
  const innerW = width - 2 * pad
  const innerH = height - 2 * pad
  const step = innerW / (series.length - 1)
  const y = (v: number) => (max === min ? height / 2 : pad + ((max - v) / (max - min)) * innerH)
  return series
    .map((v, i) => `${i === 0 ? "M" : "L"}${round(pad + i * step)} ${round(y(v))}`)
    .join(" ")
}
```

```ts
export type BadgeTone = "normal" | "elevated" | "crisis" | "unavailable" | "loading"

const TONES: Record<string, BadgeTone> = { Normal: "normal", Elevated: "elevated", Crisis: "crisis" }

/** Sidebar badge for a regime response: undefined = loading, null = request failed. */
export function regimeBadge(r: { label: string } | null | undefined): { text: string; tone: BadgeTone } {
  if (r === undefined) return { text: "REGIME …", tone: "loading" }
  const tone = r ? TONES[r.label] : undefined
  if (!tone) return { text: "REGIME UNAVAILABLE", tone: "unavailable" }
  return { text: `${r!.label.toUpperCase()} REGIME`, tone }
}
```

```ts
/** Current regime from the API, or null if the API is down or returns an error. */
export async function getRegime(fetchFn: typeof fetch = fetch): Promise<RegimeOut | null> {
  try {
    const res = await fetchFn("/api/regime", { cache: "no-store" })

  } catch {
    return null
  }
}
```
