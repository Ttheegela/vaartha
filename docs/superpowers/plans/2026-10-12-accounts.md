# Vārtā v2 — Sub-project 3: Accounts (Plaid) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Link accounts through Plaid, sync accounts / transactions / holdings into SQLite, detect subscriptions and bills ourselves, serve them through typed read endpoints, and switch the web Accounts, Spending, Bills, Goals and Home net-worth views from mock data to the API.

**Architecture:** Plaid is called over plain HTTPS with `httpx` (no generated SDK). Access tokens are Fernet-encrypted before they touch the DB. `api/sync.py` owns all writes (link, sync, recurring refresh, net-worth snapshot); `api/finance.py` owns all reads as a FastAPI router with Pydantic response models. Recurring detection is a pure Polars function in `core/recurring.py`. A deterministic `FakePlaid` (same interface as the real client) drives every test and an offline demo seed; a sandbox seed uses real Plaid Sandbox when keys exist. The web reads through a server-side `apiGet` helper plus pure adapter functions (tested) that map API shapes to the existing UI types, so v0 components barely change.

**Tech Stack:** Python 3.12, FastAPI, httpx, cryptography (Fernet), Polars, SQLite; Next.js 16 server components, react-plaid-link 5, node:test.

**Spec:** `docs/superpowers/specs/2026-10-11-varta-v2-design.md` (§3 data model + Plaid + security, §4 tool list for the read shapes, §6 pages, §8 item 3)

## Global Constraints

- Plaid environments: `sandbox` and `production` only. Hosts: `https://sandbox.plaid.com`, `https://production.plaid.com`. **The demo instance must never use `production`** (settings reject it).
- Credentials go in the `PLAID-CLIENT-ID` / `PLAID-SECRET` headers, never in request bodies, logs, exception messages, or API responses.
- Access tokens are stored only Fernet-encrypted (`items.access_token_enc`). If Plaid is configured but `TOKEN_ENCRYPTION_KEY` is missing, the app refuses to start.
- Use cached `/accounts/get` balances (free). Never call `/accounts/balance/get`.
- Plaid amount sign is kept as-is: **positive = money out, negative = money in**.
- `/transactions/sync`: loop while `has_more`; persist the cursor only after the full loop; on `TRANSACTIONS_SYNC_MUTATION_DURING_PAGINATION` restart from the original cursor (max 3 restarts).
- Recurring detection is ours (Plaid's recurring add-on is not on the Trial plan). Tolerance ±3 days for weekly/monthly; annual ±10 days (Ruling: 365 vs 366 and weekend shifts). Min occurrences: 3 weekly/monthly, 2 annual. `kind = "bill"` when `pfc_primary ∈ {RENT_AND_UTILITIES, LOAN_PAYMENTS}` or `pfc_detailed` starts with `GENERAL_SERVICES_INSURANCE`; else `"subscription"`.
- Spending/cash flow exclude `pfc_primary ∈ {TRANSFER_IN, TRANSFER_OUT}`, `pfc_detailed = LOAN_PAYMENTS_CREDIT_CARD_PAYMENT`, and pending transactions.
- Python: Polars only, docstrings on public functions/modules, named constants, no import-time I/O, tests never hit the network. `uv run pytest -q && uv run ruff check .` green.
- Web: tested modules use relative `.ts` imports; `cd web && pnpm typecheck && pnpm test && pnpm build` green. After API changes: `uv run python -m scripts.dump_openapi && (cd web && pnpm gen:api)`.
- Commits: Conventional Commits, **no `Co-Authored-By` line**.

## Review Focus

1. **Plaid error mid-sync** (`ITEM_LOGIN_REQUIRED`, network failure on page 3): no partial cursor saved, earlier items in `sync_all` still committed, item marked `login_required`, endpoint returns a per-item status instead of 500. Tests in Tasks 3 and 7.
2. **Item with no investment accounts** (`PRODUCTS_NOT_SUPPORTED` / `NO_INVESTMENT_ACCOUNTS` from holdings): sync still succeeds for accounts and transactions. Test in Task 3.
3. **Re-sync with `modified` and `removed` transactions**: rows update and delete; no duplicates; running sync twice is a no-op. Test in Task 3.
4. **Month-end and leap dates in recurring detection** (charges on the 31st, Feb 29): monthly stream detected and next date clamps to month end, not crash. Test in Task 4.
5. **Empty database** (no items linked yet): every read endpoint returns 200 with empty lists/zeros, and each web page shows an empty state, not a crash or mock data. Tests in Tasks 5, 6, 9.

```python
"""Encrypt Plaid access tokens at rest (Fernet: AES-128-CBC + HMAC)."""

from cryptography.fernet import Fernet


class TokenBox:
    """Seal and open secrets with one Fernet key."""

    def __init__(self, key: str) -> None:
        self._fernet = Fernet(key.encode())

    def seal(self, token: str) -> bytes:
        """Encrypt a token for storage."""
        return self._fernet.encrypt(token.encode())

    def open(self, blob: bytes) -> str:
        """Decrypt a stored token; raises InvalidToken if the key is wrong."""
        return self._fernet.decrypt(blob).decode()


def new_key() -> str:
    """Generate a new urlsafe base64 Fernet key."""
    return Fernet.generate_key().decode()
```

```python
"""Instance settings from environment variables."""

import os
from dataclasses import dataclass, field
from pathlib import Path

INSTANCES = ("owner", "demo")
PLAID_ENVS = ("sandbox", "production")


@dataclass(frozen=True)
class Settings:
    """Per-instance configuration. Secrets are excluded from repr."""

    db_path: Path
    instance: str
    plaid_env: str = "sandbox"
    plaid_client_id: str | None = field(default=None, repr=False)
    plaid_secret: str | None = field(default=None, repr=False)
    token_key: str | None = field(default=None, repr=False)

    def __post_init__(self) -> None:
        if self.plaid_env not in PLAID_ENVS:
            raise ValueError(f"PLAID_ENV must be one of {PLAID_ENVS}, got {self.plaid_env!r}")
        if self.instance == "demo" and self.plaid_env == "production":
            raise ValueError("the demo instance must use the Plaid sandbox")

    @property
    def plaid_configured(self) -> bool:
        """True when both Plaid credentials are present."""
        return bool(self.plaid_client_id and self.plaid_secret)

    @classmethod
    def from_env(cls) -> "Settings":
        """Read VARTA_*, PLAID_* and TOKEN_ENCRYPTION_KEY; reject invalid combinations."""
        instance = os.environ.get("VARTA_INSTANCE", "demo")
        if instance not in INSTANCES:
            raise ValueError(f"VARTA_INSTANCE must be one of {INSTANCES}, got {instance!r}")
        return cls(
            db_path=Path(os.environ.get("VARTA_DB_PATH", "data/varta.db")),
            instance=instance,
            plaid_env=os.environ.get("PLAID_ENV", "sandbox"),
            plaid_client_id=os.environ.get("PLAID_CLIENT_ID") or None,
            plaid_secret=os.environ.get("PLAID_SECRET") or None,
            token_key=os.environ.get("TOKEN_ENCRYPTION_KEY") or None,
        )
```

```python
"""Minimal Plaid REST client (httpx). Credentials travel only in headers."""

from typing import Protocol

import httpx

PLAID_HOSTS = {"sandbox": "https://sandbox.plaid.com", "production": "https://production.plaid.com"}
TIMEOUT_SECONDS = 30.0
CLIENT_NAME = "Vārtā"
COUNTRY_CODES = ["US"]
LANGUAGE = "en"
MAX_HISTORY_DAYS = 730
SYNC_PAGE_SIZE = 500
ERROR_TEXT_LIMIT = 200


class PlaidError(Exception):
    """A Plaid API error (or transport failure) with Plaid's error_code."""

    def __init__(self, code: str, message: str, status: int) -> None:
        super().__init__(f"{code}: {message}")
        self.code = code
        self.message = message
        self.status = status


class PlaidAPI(Protocol):
    """The Plaid calls Vārtā uses; implemented by PlaidClient and FakePlaid."""

    def link_token_create(self, user_id: str, products: list[str],
                          days_requested: int = MAX_HISTORY_DAYS) -> str: ...
    def exchange_public_token(self, public_token: str) -> tuple[str, str]: ...
    def accounts_get(self, access_token: str) -> dict: ...
    def transactions_sync(self, access_token: str, cursor: str | None) -> dict: ...
    def investments_holdings_get(self, access_token: str) -> dict: ...
    def sandbox_public_token_create(self, institution_id: str, products: list[str]) -> str: ...


class PlaidClient:
    """Thin JSON-over-HTTPS client for the endpoints in PlaidAPI."""

    def __init__(self, env: str, client_id: str, secret: str,
                 transport: httpx.BaseTransport | None = None) -> None:
        self._http = httpx.Client(
            base_url=PLAID_HOSTS[env],
            timeout=TIMEOUT_SECONDS,
            transport=transport,
            headers={"PLAID-CLIENT-ID": client_id, "PLAID-SECRET": secret},
        )

    def _post(self, path: str, body: dict) -> dict:
        try:
            resp = self._http.post(path, json=body)
        except httpx.HTTPError as exc:
            raise PlaidError("NETWORK_ERROR", type(exc).__name__, 0) from exc
        try:
            data = resp.json()
        except ValueError:
            data = None
        if resp.status_code >= 400 or data is None:
            if isinstance(data, dict) and "error_code" in data:
                raise PlaidError(data["error_code"], data.get("error_message", ""), resp.status_code)
            raise PlaidError(f"HTTP_{resp.status_code}", resp.text[:ERROR_TEXT_LIMIT], resp.status_code)
        return data

    def link_token_create(self, user_id: str, products: list[str],
                          days_requested: int = MAX_HISTORY_DAYS) -> str:
        """Create a Link token for the single user of this instance."""
        data = self._post("/link/token/create", {
            "client_name": CLIENT_NAME,
            "language": LANGUAGE,
            "country_codes": COUNTRY_CODES,
            "user": {"client_user_id": user_id},
            "products": products,
            "transactions": {"days_requested": days_requested},
        })
        return data["link_token"]

    def exchange_public_token(self, public_token: str) -> tuple[str, str]:
        """Exchange Link's public token for (access_token, item_id)."""
        data = self._post("/item/public_token/exchange", {"public_token": public_token})
        return data["access_token"], data["item_id"]

    def accounts_get(self, access_token: str) -> dict:
        """Cached account balances (free endpoint) plus the item."""
        return self._post("/accounts/get", {"access_token": access_token})

    def transactions_sync(self, access_token: str, cursor: str | None) -> dict:
        """One page of /transactions/sync; omit cursor for full history."""
        body: dict = {"access_token": access_token, "count": SYNC_PAGE_SIZE}
        if cursor:
            body["cursor"] = cursor
        return self._post("/transactions/sync", body)

    def investments_holdings_get(self, access_token: str) -> dict:
        """Holdings and securities for the item's investment accounts."""
        return self._post("/investments/holdings/get", {"access_token": access_token})

    def sandbox_public_token_create(self, institution_id: str, products: list[str]) -> str:
        """Sandbox only: create an item without Link."""
        data = self._post("/sandbox/public_token/create", {
            "institution_id": institution_id,
            "initial_products": products,
            "options": {"transactions": {"days_requested": MAX_HISTORY_DAYS}},
        })
        return data["public_token"]
```

```python
        txns = self.data["transactions"]

            self._pending = {"modified": [], "removed": []}
            return out

        if page == 1 and self.mutate_once:
            self.mutate_once = False
            raise PlaidError("TRANSACTIONS_SYNC_MUTATION_DURING_PAGINATION", "simulated", 400)
        chunk = txns[page * self.page_size:(page + 1) * self.page_size]
        has_more = (page + 1) * self.page_size < len(txns)
        return {"added": chunk, "modified": [], "removed": [],
                "next_cursor": f"p{page + 1}" if has_more else "done", "has_more": has_more}

        self._maybe_fail("investments_holdings_get")

        return "public-fake-1"
```

```python
"""All Plaid-driven writes: link, sync, net-worth snapshot, recurring refresh.

Plaid amount sign is preserved: positive = money out.
"""

import logging
import sqlite3
from datetime import UTC, date, datetime

from api.crypto import TokenBox
from api.plaid_client import PlaidAPI, PlaidError

log = logging.getLogger("varta.sync")

ASSET_TYPES = ("depository", "investment")
LIABILITY_TYPES = ("credit", "loan")
RESTART_CODE = "TRANSACTIONS_SYNC_MUTATION_DURING_PAGINATION"
LOGIN_REQUIRED = "ITEM_LOGIN_REQUIRED"
NO_INVESTMENTS = {"PRODUCTS_NOT_SUPPORTED", "NO_INVESTMENT_ACCOUNTS", "PRODUCT_NOT_ENABLED"}
MAX_SYNC_RESTARTS = 3


def _now() -> str:
    return datetime.now(UTC).isoformat(timespec="seconds")


def link_item(conn: sqlite3.Connection, plaid: PlaidAPI, box: TokenBox,
              public_token: str, today: date) -> str:
    """Exchange a public token, store the encrypted access token, then sync everything."""
    access_token, item_id = plaid.exchange_public_token(public_token)
    conn.execute(
        "INSERT INTO items (item_id, access_token_enc, status) VALUES (?, ?, 'active') "
        "ON CONFLICT(item_id) DO UPDATE SET access_token_enc=excluded.access_token_enc, "
        "status='active'",
        (item_id, box.seal(access_token)),
    )
    conn.commit()
    sync_item(conn, plaid, box, item_id)
    refresh_recurring(conn, today)
    snapshot_networth(conn, today)
    return item_id


def _pull_transactions(plaid: PlaidAPI, token: str, cursor: str | None):
    for _ in range(MAX_SYNC_RESTARTS + 1):
        added, modified, removed, next_cursor = [], [], [], cursor
        try:
            while True:
                page = plaid.transactions_sync(token, next_cursor)
                added += page["added"]
                modified += page["modified"]
                removed += page["removed"]
                next_cursor = page["next_cursor"]
                if not page["has_more"]:
                    return added, modified, removed, next_cursor
        except PlaidError as exc:
            if exc.code != RESTART_CODE:
                raise
            log.info("transactions changed during pagination; restarting")
    raise PlaidError(RESTART_CODE, "gave up after restarts", 0)


def _txn_row(t: dict) -> tuple:
    pfc = t.get("personal_finance_category") or {}
    return (t["transaction_id"], t["account_id"], t["date"], t["amount"],
            t.get("merchant_name") or t.get("name"), pfc.get("primary"), pfc.get("detailed"),
            int(bool(t.get("pending"))))


def sync_item(conn: sqlite3.Connection, plaid: PlaidAPI, box: TokenBox, item_id: str) -> dict[str, int]:
    """Sync one item; commit only after Plaid data is fully fetched. Returns change counts."""
    row = conn.execute("SELECT access_token_enc, txn_cursor FROM items WHERE item_id=?",
                       (item_id,)).fetchone()
    token = box.open(row["access_token_enc"])
    try:
        acc = plaid.accounts_get(token)
        added, modified, removed, cursor = _pull_transactions(plaid, token, row["txn_cursor"])
        try:
            inv = plaid.investments_holdings_get(token)
        except PlaidError as exc:
            if exc.code not in NO_INVESTMENTS:
                raise
            inv = {"holdings": [], "securities": []}
    except PlaidError as exc:
        if exc.code == LOGIN_REQUIRED:
            conn.execute("UPDATE items SET status='login_required' WHERE item_id=?", (item_id,))
            conn.commit()
        raise

    with conn:
        conn.execute("UPDATE items SET institution=?, txn_cursor=?, status='active', "
                     "last_synced_at=? WHERE item_id=?",
                     (acc["item"].get("institution_name"), cursor, _now(), item_id))
        conn.executemany(
            "INSERT OR REPLACE INTO accounts (account_id, item_id, name, type, subtype, mask, "
            "balance_current, balance_available, currency) VALUES (?,?,?,?,?,?,?,?,?)",
            [(a["account_id"], item_id, a["name"], a["type"], a["subtype"], a.get("mask"),
              a["balances"].get("current"), a["balances"].get("available"),
              a["balances"].get("iso_currency_code")) for a in acc["accounts"]])
        conn.executemany(
            "INSERT OR REPLACE INTO transactions (txn_id, account_id, date, amount, merchant, "
            "pfc_primary, pfc_detailed, pending) VALUES (?,?,?,?,?,?,?,?)",
            [_txn_row(t) for t in added + modified])
        conn.executemany("DELETE FROM transactions WHERE txn_id=?",
                         [(r["transaction_id"],) for r in removed])
        conn.executemany(
            "INSERT OR REPLACE INTO securities (security_id, ticker, name, type) VALUES (?,?,?,?)",
            [(s["security_id"], s.get("ticker_symbol"), s.get("name"), s.get("type"))
             for s in inv["securities"]])
        conn.execute("DELETE FROM holdings WHERE account_id IN "
                     "(SELECT account_id FROM accounts WHERE item_id=?)", (item_id,))
        conn.executemany(
            "INSERT INTO holdings (account_id, security_id, quantity, cost_basis, value, as_of) "
            "VALUES (?,?,?,?,?,?)",
            [(h["account_id"], h["security_id"], h.get("quantity"), h.get("cost_basis"),
              h.get("institution_value"), _now()) for h in inv["holdings"]])
    return {"added": len(added), "modified": len(modified), "removed": len(removed)}


def snapshot_networth(conn: sqlite3.Connection, today: date) -> None:
    """Write today's assets/liabilities from cached balances (one row per day)."""
    a_ph = ",".join("?" * len(ASSET_TYPES))
    l_ph = ",".join("?" * len(LIABILITY_TYPES))
    assets = conn.execute(f"SELECT COALESCE(SUM(balance_current),0) FROM accounts "
                          f"WHERE type IN ({a_ph})", ASSET_TYPES).fetchone()[0]
    liabilities = conn.execute(f"SELECT COALESCE(SUM(balance_current),0) FROM accounts "
                               f"WHERE type IN ({l_ph})", LIABILITY_TYPES).fetchone()[0]
    conn.execute("INSERT OR REPLACE INTO networth_snapshots (date, assets, liabilities) "
                 "VALUES (?,?,?)", (today.isoformat(), assets, liabilities))
    conn.commit()


def refresh_recurring(conn: sqlite3.Connection, today: date) -> int:
    """Rebuild recurring_streams from transactions. Implemented in Task 4."""
    return 0


def sync_all(conn: sqlite3.Connection, plaid: PlaidAPI, box: TokenBox, today: date) -> dict[str, str]:
    """Sync every item; one failing item never blocks the others."""
    results: dict[str, str] = {}
    for (item_id,) in conn.execute("SELECT item_id FROM items").fetchall():
        try:
            sync_item(conn, plaid, box, item_id)
            results[item_id] = "ok"
        except PlaidError as exc:
            log.warning("sync failed for %s: %s", item_id, exc.code)
            results[item_id] = exc.code
    refresh_recurring(conn, today)
    snapshot_networth(conn, today)
    return results
```

```python
"""Detect recurring outflows (subscriptions and bills) from transactions.

Our own detector, because Plaid's recurring add-on is not on the Trial plan.
A stream = same account + normalized merchant, charged on a regular cadence.
"""

import calendar
import hashlib
import statistics
from datetime import date, timedelta

import polars as pl

STREAM_SCHEMA = {
    "stream_id": pl.Utf8, "account_id": pl.Utf8, "direction": pl.Utf8, "kind": pl.Utf8,
    "merchant": pl.Utf8, "avg_amount": pl.Float64, "last_amount": pl.Float64,
    "frequency": pl.Utf8, "last_date": pl.Date, "predicted_next_date": pl.Date,
    "status": pl.Utf8, "is_active": pl.Boolean,
}
STREAM_COLUMNS = list(STREAM_SCHEMA)
WEEK_DAYS = 7
WEEKLY_TOLERANCE_DAYS = 3
MONTHLY_TOLERANCE_DAYS = 3
ANNUAL_DAYS = 365
ANNUAL_TOLERANCE_DAYS = 10
MIN_WEEKLY = MIN_MONTHLY = 3
MIN_ANNUAL = 2
TOLERANCE = {"WEEKLY": WEEKLY_TOLERANCE_DAYS, "MONTHLY": MONTHLY_TOLERANCE_DAYS,
             "ANNUALLY": ANNUAL_TOLERANCE_DAYS}
ANCHOR_WINDOW = 3  # day-of-month anchor = max day among the last 3 charges (month-end safe)
BILL_PRIMARY = {"RENT_AND_UTILITIES", "LOAN_PAYMENTS"}
BILL_DETAILED_PREFIX = "GENERAL_SERVICES_INSURANCE"
STREAM_ID_LENGTH = 16
AMOUNT_DECIMALS = 2


def _add_months(first_of_month: date, months: int) -> date:
    y, m = divmod(first_of_month.month - 1 + months, 12)
    return date(first_of_month.year + y, m + 1, 1)


def _next_date(last: date, frequency: str, anchor_day: int) -> date:
    """Next expected charge: +7 days, or +1/+12 months on anchor_day clamped to month length."""
    if frequency == "WEEKLY":
        return last + timedelta(days=WEEK_DAYS)
    target = _add_months(last.replace(day=1), 1 if frequency == "MONTHLY" else 12)
    return target.replace(day=min(anchor_day, calendar.monthrange(target.year, target.month)[1]))


def _cadence(dates: list[date]) -> str | None:
    pairs = list(zip(dates, dates[1:], strict=False))
    if not pairs:
        return None
    gaps = [(b - a).days for a, b in pairs]
    if len(dates) >= MIN_WEEKLY and all(abs(g - WEEK_DAYS) <= WEEKLY_TOLERANCE_DAYS for g in gaps):
        return "WEEKLY"
    anchor = max(d.day for d in dates)
    if len(dates) >= MIN_MONTHLY and all(
        (b.year - a.year) * 12 + b.month - a.month == 1
        and abs((b - _next_date(a, "MONTHLY", anchor)).days) <= MONTHLY_TOLERANCE_DAYS
        for a, b in pairs
    ):
        return "MONTHLY"
    if len(dates) >= MIN_ANNUAL and all(abs(g - ANNUAL_DAYS) <= ANNUAL_TOLERANCE_DAYS for g in gaps):
        return "ANNUALLY"
    return None


def _kind(primary: str | None, detailed: str | None) -> str:
    if primary in BILL_PRIMARY or (detailed or "").startswith(BILL_DETAILED_PREFIX):
        return "bill"
    return "subscription"


def detect_recurring(txns: pl.DataFrame, today: date) -> pl.DataFrame:
    """Return one row per detected outflow stream (columns: STREAM_COLUMNS)."""
    rows = []
    outflows = txns.filter((pl.col("amount") > 0) & pl.col("merchant").is_not_null())
    if outflows.height:
        grouped = (
            outflows.with_columns(pl.col("merchant").str.strip_chars().str.to_lowercase().alias("key"))
            .sort("date")
            .group_by("account_id", "key", maintain_order=True)
            .agg(pl.col("date"), pl.col("amount"), pl.col("merchant").last(),
                 pl.col("pfc_primary").last(), pl.col("pfc_detailed").last())
        )
        for g in grouped.iter_rows(named=True):
            dates, amounts = list(g["date"]), list(g["amount"])
            frequency = _cadence(dates)
            if frequency is None:
                continue
            anchor = dates[-1].day if frequency == "ANNUALLY" else max(d.day for d in dates[-ANCHOR_WINDOW:])
            nxt = _next_date(dates[-1], frequency, anchor)
            sid = hashlib.sha1(f"{g['account_id']}|{g['key']}".encode()).hexdigest()[:STREAM_ID_LENGTH]
            rows.append({
                "stream_id": sid, "account_id": g["account_id"], "direction": "outflow",
                "kind": _kind(g["pfc_primary"], g["pfc_detailed"]), "merchant": g["merchant"],
                "avg_amount": round(statistics.fmean(amounts), AMOUNT_DECIMALS),
                "last_amount": amounts[-1], "frequency": frequency, "last_date": dates[-1],
                "predicted_next_date": nxt, "status": "MATURE",
                "is_active": today <= nxt + timedelta(days=TOLERANCE[frequency]),
            })
    return pl.DataFrame(rows, schema=STREAM_SCHEMA)
```

```python
def refresh_recurring(conn: sqlite3.Connection, today: date) -> int:
    """Rebuild recurring_streams from non-pending transactions; returns stream count."""
    rows = conn.execute("SELECT account_id, date, amount, merchant, pfc_primary, pfc_detailed "
                        "FROM transactions WHERE pending=0").fetchall()
    txns = pl.DataFrame(
        [dict(r) for r in rows],
        schema={"account_id": pl.Utf8, "date": pl.Utf8, "amount": pl.Float64, "merchant": pl.Utf8,
                "pfc_primary": pl.Utf8, "pfc_detailed": pl.Utf8},
    ).with_columns(pl.col("date").str.to_date())
    streams = detect_recurring(txns, today)
    with conn:
        conn.execute("DELETE FROM recurring_streams")
        conn.executemany(
            f"INSERT INTO recurring_streams ({', '.join(STREAM_COLUMNS)}) "
            f"VALUES ({', '.join('?' * len(STREAM_COLUMNS))})",
            [tuple(v.isoformat() if isinstance(v, date) else v for v in r)
             for r in streams.select(STREAM_COLUMNS).iter_rows()])
    return streams.height
```

```python
"""Read-only finance endpoints over SQLite. All writes live in api/sync.py."""

from collections.abc import Callable
from contextlib import closing
from datetime import date, timedelta
from pathlib import Path
from typing import Literal

from fastapi import APIRouter, Query
from pydantic import BaseModel

from api.db import connect
from api.sync import LIABILITY_TYPES

WEEKS_PER_MONTH = 52 / 12
MONTHS_PER_YEAR = 12
DEFAULT_NETWORTH_DAYS = 365
MAX_NETWORTH_DAYS = 3650


class ItemOut(BaseModel):
    item_id: str
    institution: str | None
    status: str
    last_synced_at: str | None


class AccountOut(BaseModel):
    account_id: str
    institution: str | None
    name: str
    type: str
    subtype: str | None
    mask: str | None
    balance_current: float | None
    balance_available: float | None
    is_liability: bool


class AccountsOut(BaseModel):
    accounts: list[AccountOut]
    items: list[ItemOut]
    assets: float
    liabilities: float


class NetWorthPoint(BaseModel):
    date: str
    assets: float
    liabilities: float
    net: float


class RecurringOut(BaseModel):
    stream_id: str
    merchant: str
    kind: Literal["subscription", "bill", "income"]
    frequency: Literal["WEEKLY", "MONTHLY", "ANNUALLY"]
    avg_amount: float
    last_amount: float
    last_date: str
    predicted_next_date: str
    is_active: bool
    monthly_amount: float


class RecurringListOut(BaseModel):
    subscriptions: list[RecurringOut]
    bills: list[RecurringOut]
    subscriptions_monthly: float
    bills_monthly: float


def monthly_amount(amount: float, frequency: str) -> float:
    """Average monthly cost of a recurring charge."""
    if frequency == "WEEKLY":
        return amount * WEEKS_PER_MONTH
    if frequency == "ANNUALLY":
        return amount / MONTHS_PER_YEAR
    return amount


def build_finance_router(db_path: Path, today: Callable[[], date]) -> APIRouter:
    """Routes for accounts, net worth and recurring charges."""
    router = APIRouter(prefix="/api")

    @router.get("/accounts", response_model=AccountsOut)
    def accounts() -> AccountsOut:
        """Linked accounts with cached balances, items, and asset/liability totals."""
        with closing(connect(db_path)) as conn:
            items = [ItemOut(**dict(r)) for r in conn.execute(
                "SELECT item_id, institution, status, last_synced_at FROM items ORDER BY institution")]
            rows = conn.execute(
                "SELECT a.account_id, i.institution, a.name, a.type, a.subtype, a.mask, "
                "a.balance_current, a.balance_available FROM accounts a "
                "JOIN items i USING (item_id) ORDER BY i.institution, a.name").fetchall()
        accts = [AccountOut(**dict(r), is_liability=r["type"] in LIABILITY_TYPES) for r in rows]
        return AccountsOut(
            accounts=accts, items=items,
            assets=sum(a.balance_current or 0 for a in accts if not a.is_liability),
            liabilities=sum(a.balance_current or 0 for a in accts if a.is_liability),
        )

    @router.get("/networth", response_model=list[NetWorthPoint])
    def networth(days: int = Query(DEFAULT_NETWORTH_DAYS, ge=1, le=MAX_NETWORTH_DAYS)):
        """Daily net-worth snapshots for the last `days` days, oldest first."""
        cutoff = (today() - timedelta(days=days)).isoformat()
        with closing(connect(db_path)) as conn:
            rows = conn.execute("SELECT date, assets, liabilities FROM networth_snapshots "
                                "WHERE date >= ? ORDER BY date", (cutoff,)).fetchall()
        return [NetWorthPoint(**dict(r), net=r["assets"] - r["liabilities"]) for r in rows]

    @router.get("/recurring", response_model=RecurringListOut)
    def recurring() -> RecurringListOut:
        """Detected subscriptions and bills with monthly-normalized totals (inactive excluded)."""
        with closing(connect(db_path)) as conn:
            rows = conn.execute(
                "SELECT stream_id, merchant, kind, frequency, avg_amount, last_amount, last_date, "
                "predicted_next_date, is_active FROM recurring_streams "
                "ORDER BY predicted_next_date").fetchall()
        streams = [RecurringOut(**{**dict(r), "is_active": bool(r["is_active"])},
                                monthly_amount=monthly_amount(r["last_amount"], r["frequency"]))
                   for r in rows]
        subs = [s for s in streams if s.kind == "subscription"]
        bills = [s for s in streams if s.kind == "bill"]
        return RecurringListOut(
            subscriptions=subs, bills=bills,
            subscriptions_monthly=sum(s.monthly_amount for s in subs if s.is_active),
            bills_monthly=sum(s.monthly_amount for s in bills if s.is_active),
        )

    return router
```

```python
    @router.get("/spending", response_model=SpendingOut)
    def spending(month: str | None = None) -> SpendingOut:
        """Spend by category and top merchants for a month, plus 6 months of cash flow."""
        month = month or today().strftime("%Y-%m")
        if not MONTH_RE.match(month):
            raise HTTPException(status_code=422, detail="month must be YYYY-MM")
        months = _months_back(month, CASH_FLOW_MONTHS)
        with closing(connect(db_path)) as conn:
            cats = conn.execute(
                f"SELECT pfc_primary AS category, SUM(amount) AS amount FROM transactions "
                f"WHERE {_COUNTED} AND amount > 0 AND substr(date,1,7)=? AND pfc_primary IS NOT NULL "
                f"GROUP BY pfc_primary ORDER BY amount DESC", (*_COUNTED_ARGS, month)).fetchall()
            merchants = conn.execute(
                f"SELECT merchant, MAX(pfc_primary) AS category, SUM(amount) AS amount, "
                f"COUNT(*) AS count FROM transactions WHERE {_COUNTED} AND amount > 0 "
                f"AND substr(date,1,7)=? AND merchant IS NOT NULL GROUP BY merchant "
                f"ORDER BY amount DESC LIMIT ?", (*_COUNTED_ARGS, month, TOP_MERCHANTS)).fetchall()
            flows = {r["month"]: r for r in conn.execute(
                f"SELECT substr(date,1,7) AS month, "
                f"SUM(CASE WHEN amount < 0 THEN -amount ELSE 0 END) AS income, "
                f"SUM(CASE WHEN amount > 0 THEN amount ELSE 0 END) AS spend FROM transactions "
                f"WHERE {_COUNTED} AND substr(date,1,7) BETWEEN ? AND ? GROUP BY month",
                (*_COUNTED_ARGS, months[0], months[-1])).fetchall()}
        return SpendingOut(
            month=month,
            by_category=[CategorySpend(**dict(r)) for r in cats],
            by_merchant=[MerchantSpendOut(**dict(r)) for r in merchants],
            cash_flow=[CashFlowMonth(month=m, income=flows[m]["income"] if m in flows else 0,
                                     spend=flows[m]["spend"] if m in flows else 0) for m in months],
        )

    @router.get("/budgets", response_model=list[BudgetOut])
    def budgets() -> list[BudgetOut]:
        """Monthly budgets with this month's spend per category."""
        month = today().strftime("%Y-%m")
        with closing(connect(db_path)) as conn:
            rows = conn.execute(
                f"SELECT b.pfc_primary AS category, b.monthly_limit AS 'limit', "
                f"COALESCE((SELECT SUM(amount) FROM transactions t WHERE t.pfc_primary=b.pfc_primary "
                f"AND t.amount > 0 AND substr(t.date,1,7)=? AND {_COUNTED}), 0) AS spent "
                f"FROM budgets b ORDER BY b.pfc_primary", (month, *_COUNTED_ARGS)).fetchall()
        return [BudgetOut(**dict(r)) for r in rows]

    @router.get("/goals", response_model=list[GoalOut])
    def goals() -> list[GoalOut]:
        """Goals with current balance of linked accounts and months remaining."""
        now = today()
        with closing(connect(db_path)) as conn:
            balances = {r["account_id"]: r["balance_current"] or 0
                        for r in conn.execute("SELECT account_id, balance_current FROM accounts")}
            rows = conn.execute("SELECT id, name, target_amount, target_date, account_ids "
                                "FROM goals ORDER BY id").fetchall()
        out = []
        for r in rows:
            current = sum(balances.get(a, 0) for a in json.loads(r["account_ids"]))
            months_left = None
            if r["target_date"]:
                t = date.fromisoformat(r["target_date"])
                months_left = max(0, (t.year - now.year) * 12 + t.month - now.month)
            out.append(GoalOut(id=r["id"], name=r["name"], target_amount=r["target_amount"],
                               target_date=r["target_date"], current=current,
                               progress=min(1.0, current / r["target_amount"]) if r["target_amount"] else 0.0,
                               months_left=months_left))
        return out
```

```python
"""Seed a demo database: Plaid data plus budgets and goals.

Run: uv run python -m scripts.seed_demo --source fake      (offline, deterministic)
     uv run python -m scripts.seed_demo --source sandbox   (needs PLAID_CLIENT_ID/SECRET, sandbox)
Reads VARTA_DB_PATH and TOKEN_ENCRYPTION_KEY from the environment.
"""

import argparse
import json
from contextlib import closing
from datetime import date

from api.crypto import TokenBox
from api.db import connect, init_db
from api.plaid_client import PlaidAPI, PlaidClient
from api.plaid_fake import FakePlaid
from api.settings import Settings
from api.sync import link_item

SANDBOX_INSTITUTION = "ins_109508"
SANDBOX_PRODUCTS = ["transactions", "investments"]
DEMO_BUDGETS = {"FOOD_AND_DRINK": 600, "GENERAL_MERCHANDISE": 500,
                "TRANSPORTATION": 350, "ENTERTAINMENT": 300}
# name, target amount, target date, account subtypes that fund it
DEMO_GOALS = [
    ("Emergency fund", 25000.0, "2027-06-30", ["savings"]),
    ("Japan trip", 6000.0, "2027-04-01", ["checking"]),
    ("Brokerage to 75k", 75000.0, "2028-12-31", ["brokerage"]),
]


def seed(settings: Settings, source: str, today: date, plaid: PlaidAPI | None = None) -> str:
    """Link one item from `source`, then upsert demo budgets and goals. Returns item_id."""
    if not settings.token_key:
        raise ValueError("TOKEN_ENCRYPTION_KEY is required to store Plaid tokens")
    if plaid is None:
        if source == "fake":
            plaid = FakePlaid(today)
        else:
            if not settings.plaid_configured or settings.plaid_env != "sandbox":
                raise ValueError("sandbox seed needs PLAID_CLIENT_ID/PLAID_SECRET and PLAID_ENV=sandbox")
            plaid = PlaidClient("sandbox", settings.plaid_client_id, settings.plaid_secret)
    public_token = plaid.sandbox_public_token_create(SANDBOX_INSTITUTION, SANDBOX_PRODUCTS)
    with closing(connect(settings.db_path)) as conn:
        init_db(conn)
        item_id = link_item(conn, plaid, TokenBox(settings.token_key), public_token, today)
        conn.executemany("INSERT OR REPLACE INTO budgets (pfc_primary, monthly_limit) VALUES (?, ?)",
                         list(DEMO_BUDGETS.items()))
        by_subtype: dict[str, list[str]] = {}
        for r in conn.execute("SELECT account_id, subtype FROM accounts"):
            by_subtype.setdefault(r["subtype"], []).append(r["account_id"])
        conn.executemany("DELETE FROM goals WHERE name=?", [(g[0],) for g in DEMO_GOALS])
        conn.executemany(
            "INSERT INTO goals (name, target_amount, target_date, account_ids) VALUES (?,?,?,?)",
            [(name, target, when, json.dumps([a for s in subs for a in by_subtype.get(s, [])]))
             for name, target, when, subs in DEMO_GOALS])
        conn.commit()
    return item_id


if __name__ == "__main__":
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--source", choices=["fake", "sandbox"], default="fake")
    args = parser.parse_args()
    item = seed(Settings.from_env(), args.source, date.today())
    print(f"seeded item {item}")
```

```ts
/** GET from the API on the server; null when the API is down or errors. */
export async function apiGet<T>(path: string): Promise<T | null> {
```

```ts
import type { components } from "./api-types.ts"
import type { Account, Bill, Budget, Goal, MerchantSpend } from "./types.ts"

type S = components["schemas"]
type Recurring = S["RecurringOut"]

const FREQUENCY: Record<Recurring["frequency"], Bill["frequency"]> = {
  WEEKLY: "Weekly", MONTHLY: "Monthly", ANNUALLY: "Annual",
}
const PRICE_EPSILON = 0.005
const MONTH_FMT = new Intl.DateTimeFormat("en-US", { month: "short", timeZone: "UTC" })
const DAY_FMT = new Intl.DateTimeFormat("en-US", { month: "short", day: "numeric", timeZone: "UTC" })

const utc = (iso: string) => new Date(`${iso}T00:00:00Z`)
const sameMonth = (iso: string, today: Date) =>
  iso.slice(0, 7) === `${today.getUTCFullYear()}-${String(today.getUTCMonth() + 1).padStart(2, "0")}`
const cents = (n: number) => Math.round(n * 100) / 100

export function categoryLabel(pfc: string): string {
  const words = pfc.toLowerCase().split("_")
  return words.map((w, i) => (i === 0 ? w[0].toUpperCase() + w.slice(1) : w)).join(" ")
}

export function toAccounts(a: S["AccountsOut"]): Account[] {
  return a.accounts.map((x) => ({
    id: x.account_id, institution: x.institution ?? "Unknown", name: x.name, type: x.subtype ?? x.type,
    mask: x.mask ?? "", balance: x.balance_current ?? 0, liability: x.is_liability,
  }))
}

export function toBills(r: S["RecurringListOut"], today: Date): Bill[] {
  return [...r.subscriptions, ...r.bills].map((s) => {
    const next = sameMonth(s.predicted_next_date, today)
    const last = !next && sameMonth(s.last_date, today)
    const placed = next ? s.predicted_next_date : last ? s.last_date : null
    const diff = s.last_amount - s.avg_amount
    return {
      id: s.stream_id, merchant: s.merchant, amount: s.last_amount,
      day: placed ? utc(placed).getUTCDate() : 0, date: DAY_FMT.format(utc(s.predicted_next_date)),
      frequency: FREQUENCY[s.frequency], kind: s.kind === "bill" ? "bill" : "subscription",
      paid: Boolean(last), inactive: !s.is_active, priceUp: diff > PRICE_EPSILON ? cents(diff) : undefined,
    }
  })
}

export function toBudgets(b: S["BudgetOut"][]): Budget[] {
  return b.map((x) => ({ category: categoryLabel(x.category), spent: x.spent, limit: x.limit }))
}

export function toGoals(g: S["GoalOut"][]): Goal[] {
  return g.map((x) => ({
    name: x.name, current: x.current, target: x.target_amount,
    targetDate: x.target_date ? DAY_FMT.format(utc(x.target_date)) : "No date",
    projectedDate: x.months_left === null ? "—" : `${x.months_left} months left`,
    status: x.progress >= 1 || x.months_left !== 0 ? "On track" : "Behind",
  }))
}

export function toCategorySpend(s: S["SpendingOut"]) {
  return s.by_category.map((c) => ({ name: categoryLabel(c.category), value: cents(c.amount) }))
}

export function toMerchantSpend(s: S["SpendingOut"]): MerchantSpend[] {
  return s.by_merchant.map((m) => ({
    merchant: m.merchant, category: m.category ? categoryLabel(m.category) : "Other",
    amount: cents(m.amount), transactions: m.count,
  }))
}

export function toCashFlow(s: S["SpendingOut"]) {
  return s.cash_flow.map((c) => ({ month: MONTH_FMT.format(utc(`${c.month}-01`)), income: cents(c.income), spend: cents(c.spend) }))
}

export function toNetWorth(points: S["NetWorthPoint"][]) {
  const byMonth = new Map<string, number>()
  for (const p of points) byMonth.set(p.date.slice(0, 7), p.net)
  return [...byMonth].map(([m, v]) => ({ month: MONTH_FMT.format(utc(`${m}-01`)), value: cents(v) }))
}
```

```tsx
"use client"
import { useCallback, useEffect, useState } from "react"
import { useRouter } from "next/navigation"
import { usePlaidLink } from "react-plaid-link"
import { Link2 } from "lucide-react"
import { Button } from "@/components/ui/button"

export function LinkAccountButton() {
  const router = useRouter()
  const [token, setToken] = useState<string | null>(null)
  const [error, setError] = useState<string | null>(null)
  const [busy, setBusy] = useState(false)

  useEffect(() => {
    fetch("/api/plaid/link_token", { method: "POST" })
      .then(async (r) => (r.ok ? setToken((await r.json()).link_token) : setError("Account linking is unavailable")))
      .catch(() => setError("Account linking is unavailable"))
  }, [])

  const onSuccess = useCallback(async (publicToken: string | null) => {
    if (!publicToken) return
    setBusy(true)
    const r = await fetch("/api/plaid/exchange", {
      method: "POST", headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ public_token: publicToken }),
    })
    setBusy(false)
    if (r.ok) router.refresh()
    else setError("Couldn't link that account. Try again.")
  }, [router])

  const { open, ready } = usePlaidLink({ token, onSuccess })
  return (
    <div className="flex flex-col items-end gap-1">
      <Button onClick={() => open()} disabled={!ready || busy} className="action-label">
        <Link2 /> {busy ? "LINKING…" : "LINK ACCOUNT"}
      </Button>
      {error && <p className="text-xs text-muted-foreground">{error}</p>}
    </div>
  )
}
```

```tsx
export function SyncButton() {

  const [note, setNote] = useState<string | null>(null)
  async function sync() {
    setBusy(true)

    setBusy(false)
    if (!r?.ok) return setNote("Sync unavailable")
    const failed = Object.values((await r.json()).items as Record<string, string>).filter((s) => s !== "ok")
    setNote(failed.length ? `${failed.length} account(s) need attention` : null)
    router.refresh()
  }
  return (
    <span className="inline-flex items-center gap-2">
      <Button variant="ghost" size="sm" onClick={sync} disabled={busy}><RefreshCw className={busy ? "animate-spin" : ""} /> Sync now</Button>
      {note && <span className="text-xs text-muted-foreground">{note}</span>}
    </span>
  )
}
```
